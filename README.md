# MyLeague
Tracy Babe Ruth is a non-profit youth recreational baseball and softball league serving over 300 players, ages 3-16. The League organizes player registration, teams, games, practices, and field assignments. The league is supported by board members, team managers, coaches, umpires, parents, volunteers, and sponsors.


## Running the project

1. Install Node.js (LTS) and MySQL, then create the `tracy_babe_ruth` database and a `tbr_app` user.
2. Copy `.env.example` to `.env` and fill in your database password.
3. Run `npm install` in the project root, and again inside `client`.
4. Run `npm run dev:all` in the project root (or `npm run dev` in the root and `npm run dev` inside `client`, in two terminals).
5. Open http://localhost:5173.
